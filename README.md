# Linux System Health Report

[![ShellCheck](https://github.com/acarmochoa8626/linux-system-health-report/actions/workflows/shellcheck.yml/badge.svg)](https://github.com/acarmochoa8626/linux-system-health-report/actions/workflows/shellcheck.yml)

A Bash script that prints a quick health report for a Linux system: host details, CPU load, memory, disk usage, logged-in users, and the top memory-consuming processes.

Built as a hands-on project to practice Linux command-line tools, Bash scripting, and Git workflows.
